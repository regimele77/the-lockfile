Where data lives

The Lockfile is built to run on hosts you control. Repo content, scan results, findings, and account data stay in your deployment unless you send them out yourself.

What this instance may store

  • Session data for people who sign in through GitHub
  • Repo metadata you connect (name, id, visibility)
  • Scan jobs and findings
  • Logs from Django, Celery, and the host

GitHub access

After you install the GitHub App, access follows the permissions you approve on GitHub. The app does not need to ship repo data to thelockfile.com to run.

Cookies

Signed-in pages use session cookies. This shell does not load ad trackers.

Who is responsible

The person or team running the instance owns retention, access control, backups, and any disclosure rules for their org.
